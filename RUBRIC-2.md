# Map Rubric 2 — Revised (saved 2026-10-18)

A new rubric for park maps. Score each design 1–5 on the four rows below. Highest total wins.

| Revised criterion | Points | What earns full marks |
|---|---:|---|
| Find things quickly | /5 | Entrances, campgrounds, and key sights are easy to find on a phone; labels don’t overlap. |
| Choose a realistic visit | /5 | Stops include time needed, walking difficulty, and which places fit together in a trip. |
| Trust the information | /5 | Locations and road connections are accurate; sources and date checked are clear; visitors can check current conditions. |
| Comfortable and appealing to use | /5 | Readable text, clear symbols, easy controls, and a welcoming appearance. |
| **Total** | **/20** | |

*Plus: one honest weakness per design.*
