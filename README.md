# National Park Maps

Interactive national park maps: a hub page with park buttons plus the Joshua Tree and Death Valley maps.

## What's in this repo

- `national-park-maps.html` — the interactive maps (hub + Joshua Tree + Death Valley), one self-contained file. Open it in a browser.
- `RUBRIC.md` — the rubric used to score the map designs (Option A scorecard + R5 + R6).
- `AGENTS.md` — how to work with the user on this project (plain words, interview before building, rubric + one honest weakness).

## Note

The maps are stylized illustrations — shapes and distances are approximate, not for navigation.
